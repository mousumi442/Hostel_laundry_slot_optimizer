# 🧺 Hostel Laundry Slot Optimizer

## 📌 About the Project
The Hostel Laundry Slot Optimizer is a C++ based application designed to manage laundry bookings in hostels. It helps students book laundry slots, check machine availability, view existing bookings, and cancel reservations.

The main objective is to reduce waiting time, avoid booking conflicts, and make hostel laundry management easier.

## ✨ Features
- **Book Laundry Slots:** Students can book available laundry slots.
- **View Bookings:** Display all active laundry reservations.
- **Cancel Bookings:** Cancel an existing reservation using the student's name.
- **Machine Status:** Check the availability of washing machines.
- **Slot Management:** Manage 10 time slots and 2 washing machines.

## 🛠️ Technologies Used
- Programming Language: C++
- Concepts: Object-Oriented Programming (OOP)
- Header Files: `iostream`, `string`

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/mousumi442/Hostel_laundry_slot_optimizer
   ```
2. Open the project folder.
3. Compile the program:
   ```bash
   g++ main.cpp -o laundry
   ```
4. Run the program:
   ```bash
   ./laundry
   ```

On Windows, run:
```bash
laundry.exe
```
